# inspect-car

二手车检测评估工具（微信小程序）

## 项目目标

面向车辆检测评估师，提供车辆信息登记、专项检测、现场照片取证、报告审核与历史报告管理能力。首期以乘用车检测 MVP 为主，摩托车检测独立规划。

## MVP 页面

1. 首页：乘用车检测、摩托车检测入口及车辆查询入口
2. 业务选择：新车 / 二手车
3. 检测配置：检测类型、机构信息及报告模板
4. 现场检测：按项目分组记录结果、照片与说明
5. 审核：检测结果复核及报告确认
6. 个人中心：订单、历史报告及评估师资料

## 技术路线（首期）

- 微信原生小程序 + TypeScript
- 先完成可运行的前端交互原型，再接入服务端、数据库、对象存储和车辆查询 API
- 预留机构隔离、角色权限、检测记录版本及审计日志
