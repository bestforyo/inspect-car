# 本机订单、审核与报告原型

## 已实现流程

1. 首页点击“新建检测订单”，录入车辆档案。
2. 选择乘用车新车/二手车或摩托车业务。
3. 进入检测页面，逐项填写状态、备注和照片。
4. 检测页保存记录到订单；点击“提交审核”进入本机演示审核队列。
5. 审核工作台可选择订单，填写意见、退回修改或演示通过。
6. 订单列表可查看订单状态并打开报告预览。

## 数据存储边界

- 订单、车辆档案、检测记录均使用微信本地 Storage。
- 检测照片使用本地文件路径，报告预览依赖当前设备文件仍然存在。
- 不同微信设备之间不共享数据；清理小程序数据可能造成数据丢失。
- 当前无账号、服务端数据库、机构隔离、云端图片、消息通知或操作审计。
- 审核按钮仅更新本地状态，不代表真实机构审核。
- 报告页面仅展示记录，不构成正式鉴定评估报告；未实现 PDF、电子签名、盖章或报告防伪。

## 后续服务端化建议

将本地 `order-store` 抽象为 repository 接口。服务端实现需包含用户身份、机构 ID、订单权限、状态机、版本控制、幂等提交、审核操作日志、图片对象存储和报告归档。不得将本地演示状态直接迁移为正式业务结论。
