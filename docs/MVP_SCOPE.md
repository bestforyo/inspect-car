# inspect-car MVP 范围

## 首期目标

先交付可在微信开发者工具中运行的原生小程序前端原型，验证评估师的检测流程和现场录入体验。

## 页面范围

- 工作台：乘用车、摩托车入口；最近任务展示
- 业务选择：乘用车新车/二手车；摩托车入口独立
- 现场检测：重大事故、泡水、火烧专项分组；状态选择和文字说明
- 我的：评估师资料、订单/报告/模板入口占位

## 当前明确未完成

- 完整竞品检测项导入与逐图校准（当前代码仅为部分演示项目）
- VIN/车牌第三方车辆查询
- 相机拍照、相册上传、云端对象存储
- 检测草稿持久化、离线同步
- 审核工作流、正式报告 PDF、电子签名/机构盖章
- 服务端、数据库、机构与角色权限
- 标准条款映射及重大事故/泡水/火烧自动判定
- 摩托车独立标准和检测模板

## 重要边界

当前页面只记录演示状态，不输出正式鉴定结论。竞品截图项目是产品设计基线，不应被描述为标准原文要求。重大事故、泡水、火烧结论须在标准条款、组合条件和证据要求完成核验后才可启用。

## 本地运行

1. 安装微信开发者工具。
2. 克隆仓库并切换到 feature/mvp-bootstrap。
3. 使用微信开发者工具导入仓库根目录。
4. 当前 project.config.json 使用 touristappid 占位，发布前替换为实际小程序 AppID。
5. 如需类型检查，执行 npm install 后运行 npm run typecheck。
